# 智能符号化模拟电路分析系统 (ISACA)
# 项目概述

本项目面向模拟电路设计与教学场景，构建了一套从**电路原理图（图像）** 到**可解析的 SPICE 网表**，再到**符号化电路分析报告**的全流程智能系统。系统融合计算机视觉、OCR 文本识别、深度学习、符号计算（SLiCAP）与大语言模型技术，解决了传统电路分析中 “图文语义割裂”“网表缺乏可解释性”“符号化分析门槛高” 等核心痛点，最终输出包含传递函数、零极点分析、噪声贡献、参数敏感度的结构化分析报告，兼具工程实用性与教学可视化价值。

## 系统架构

### 核心模块说明

#### 1. 网表生成模块 (Netlistify)

- **核心能力**：将电路原理图（图像）转换为带语义信息的标准 SPICE 网表。
- **关键技术**：
    
    - 目标检测（YOLOv8）：定位元器件并分类（电阻、电容、MOS 管等）；
    - 方向判定（ResNet）：识别元器件摆放方向；
    - 拓扑分析（Transformer）：提取元器件间的连接关系；
    - OCR 文本识别（PaddleOCR/Tesseract）：识别图片中的元器件标签（如`R_load`、`Vin`）与端口语义（如`Vout`、`Vbias`）；
    - 几何匹配算法：将 OCR 识别的文本与 YOLO 检测的元器件 / 端口绑定，解决 “命名不匹配”“端口无语义” 问题。
    
- **输出**：带语义标注的 SPICE 网表（.sp/.cir），并生成 IR JSON（保留原始图文映射关系）。

#### 2. 中间表示层

- **核心定位**：实现 “网表解析” 与 “符号计算” 的解耦，是全流程数据流转的核心载体。
- **关键设计**：
    
    - 保存 SPICE 网表的原始信息（器件参数、节点连接、子电路定义、模型语句）；
    - 维护 “原始图片文本→网表元器件→符号化参数” 的全链路追溯映射；
    - 存储符号化小信号模型参数（如`gm_M1`、`gds_M1`、`ro_M1`）；
    - 记录分析过程中的错误 / 警告信息（如参数缺失、未知模型）。
    
- **Schema 规范**：覆盖节点映射、器件字段、原始行追溯、小信号符号映射表、端口语义标注等核心字段，保证数据一致性与可扩展性。

#### 3. 符号计算引擎 (SLiCAP)

- **核心能力**：基于 SLiCAP 库实现模拟电路的符号化分析，避免数值计算丢失物理意义。
- **核心分析能力**：
    
    - 拉普拉斯传递函数推导；
    - 零极点分析与主导项提取；
    - 时域响应（逆拉普拉斯变换）；
    - 噪声分析（器件噪声贡献分解、频段集成）；
    - DC / 参数扫描与灵敏度分析。
    
- **关键适配**：将网表转换为 SLiCAP 可识别的电路对象，实现符号化小信号模型的无缝接入。

#### 4. 符号化简与报告生成模块

- **符号化简**：将 SLiCAP 展平后的小信号网络转换为信号流图（SFG）。算法先 比较未化简 SFG 与 SLiCAP 参考传递函数，确认两者等价；再根据数值极点和零点在 对数频率轴上进行根聚类，将完整频率范围划分为若干子区间。

在每个子区间中，算法依据支路和回路的局部主导关系执行图化简操作，并用 该频段内的传递函数幅值/相位误差决定是否接受操作。最终输出每个频段的化简 SFG、 可读符号传递函数、局部零极点表达式、数值频率、主导参数和误差记录，给出更适合分析电路工作机理的分频段解析结果。

- **报告生成**：
    
    - 结构化数据输出：LaTeX 格式公式、零极点表格、噪声贡献图、参数扫描热力图；
    - LLM 增强：将结构化符号数据注入大语言模型，生成自然语言分析报告（含电路拓扑分析、公式解释、性能评估、应用场景建议）；
    - 全链路追溯：报告中任意公式 / 结论可回溯到原始网表行或电路图对应位置。
    

#### 5. 前端交互层 (Gradio)

- **核心功能**：
    
    - 电路图片 / SPICE 网表上传；
    - 实时展示网表生成结果、IR 中间数据、符号化小信号模型；
    - 可视化呈现符号公式（KaTeX 渲染）、零极点图、时域波形、噪声谱；
    - 自然语言问答接口：基于分析报告的语义检索与 LLM 交互；
    - 结果导出：网表、分析报告、图表文件下载。

## 核心解决的问题

### 1. 符号化分析门槛高问题

- **传统痛点**：手动推导传递函数、零极点等符号表达式效率低、易出错，数值仿真丢失物理意义；
- **解决方案**：基于 SLiCAP 实现全自动化符号推导，结合化简算法输出可读的解析解，配套 LLM 自然语言解释，降低电路分析门槛。

### 2. 全流程可追溯性问题

- **传统痛点**：分析结果与原始电路图 / 网表割裂，难以定位公式 / 结论对应的物理器件；
- **解决方案**：通过 IR 层维护全链路映射，实现 “报告公式→符号参数→网表元器件→电路图位置” 的一键回溯，适配教学与工程调试场景。

## 关键功能

### 1. 图文联动的网表生成

- 输入：电路原理图（图片）；
- 输出：
    
    - 带语义标注的 SPICE 网表（元器件名匹配图片标签，端口名匹配`Vin`/`Vout`等）；
    - 可视化拓扑图（标注元器件、节点、端口语义）；
    - IR JSON（保留图文映射与原始信息）。
    

### 2. 符号化电路分析

- 基础分析：拉普拉斯传递函数、节点电压矩阵方程推导；
- 进阶分析：零极点提取、时域响应、噪声贡献分析、参数扫描与灵敏度分析；
- 公式优化：自动化简符号表达式，输出 LaTeX 格式公式（支持直接渲染）。

### 3. 智能分析报告

- 结构化内容：电路拓扑表、公式渲染、零极点清单、噪声贡献图、参数敏感度排序；
- 自然语言解读：LLM 生成的分析报告（含电路类型判断、公式物理意义、性能评估、应用场景建议）；
- 全链路追溯：任意结论可回溯到原始网表 / 电路图位置。

### 4. 交互式前端

- 支持电路图片 / SPICE 网表双输入；
- 实时展示分析过程（网表生成、符号计算、报告生成）；
- 可视化组件：公式渲染、零极点图、时域波形、参数扫描热力图；
- 问答功能：基于分析结果的自然语言交互（如 “解释该电路的主导极点”“分析 R_load 对增益的影响”）。

## 快速开始

### 环境准备

bash

运行

```
# 克隆项目
git clone <项目仓库地址>

# 创建虚拟环境
conda create -n isaca python=3.10
conda activate isaca

# 安装依赖
pip install -r requirements.txt

# 配置环境变量（LLM API Key、SLiCAP路径等）
export DASHSCOPE_API_KEY=<你的通义千问API Key>
```

### 运行系统

bash

运行

```
# 启动Gradio前端
python packup2.py
```

### 核心使用流程

1. **上传输入**：在 Gradio 界面上传电路原理图（图片）或直接输入 SPICE 网表；
2. **网表生成**：系统自动完成 OCR 识别、拓扑分析，生成带语义的网表并展示数据；
3. **符号分析**：点击 “开始分析”；
4. **查看结果**：
    
    - 查看符号公式、零极点图、时域波形等可视化结果；
    - 阅读 LLM 生成的自然语言分析报告；
    - 通过 “追溯” 功能查看公式 / 结论对应的原始元器件 / 电路图位置；
    
5. **导出结果**：下载网表、分析报告、图表文件。

## 应用场景

### 1. 工程研发

- 快速将电路草图转换为可仿真的网表，减少手动编写网表的工作量；
- 自动化符号化分析，快速定位电路关键特性（如主导极点、噪声主要来源）；
- 参数敏感度分析，指导电路参数优化。

### 2. 教学场景

- 可视化展示电路拓扑→符号公式→物理意义的推导过程；
- 全链路追溯功能帮助学生理解 “公式对应器件” 的物理联系；
- LLM 自然语言解释降低符号化分析的学习门槛。

## 后续优化方向

1. **符号化简算法升级**：引入更智能的化简策略（如基于机器学习的表达式可读性优化）；
2. **模型轻量化**：优化 YOLO/Transformer 模型，降低端侧部署成本；
3. **多格式兼容**：支持更多电路绘图工具的输出格式（如 Altium、Cadence 原理图导出格式）；
4. **教学定制化**：增加 “分步推导” 功能，适配课堂教学场景；
5. **云端部署**：支持多用户并发访问，提供在线分析服务。

## 技术亮点

1. **语义化网表生成**：解决了传统图像转网表 “有结构无语义” 的行业痛点，实现图文语义联动；
2. **解耦式架构设计**：基于 IR 中间层实现模块解耦，便于单独升级网表生成、符号计算、LLM 等模块；
3. **符号化 + LLM 融合**：将符号计算的严谨性与 LLM 的自然语言解释能力结合，兼顾工程精度与可读性；
4. **全链路追溯**：从分析报告回溯到原始电路图 / 网表，提升结果的可解释性与调试效率；
5. **轻量化前端**：基于 Gradio 快速构建交互界面，降低部署与使用门槛，兼顾开发效率与用户体验。
